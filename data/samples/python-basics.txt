#装饰器
装饰器本质上是一个接收函数作为参数、并返回新函数的高阶函数。它让你在不修改原函数代码的前提下，给函数加上日志记录、权限校验、计时统计等通用逻辑。使用时只需在被装饰函数上方写一行 @decorator_name，Python 会在定义时自动完成包装。装饰器还可以带参数，这时需要再嵌套一层函数来接收配置项。
#列表推导式
列表推导式是用一行代码快速生成列表的语法糖，写法形如 [表达式 for 变量 in 可迭代对象 if 条件]。它比等价的 for 循环加 append 更简洁，而且通常执行速度也更快，因为底层由 C 语言实现。推导式还可以嵌套使用，比如展平二维列表：[x for row in matrix for x in row]。不过当逻辑过于复杂时，建议还是写成普通循环，可读性更重要。
#异常处理
Python 用 try / except / else / finally 结构来捕获和处理运行时错误。try 块中放可能出错的代码，except 块负责处理特定异常类型，else 在没有异常时执行，finally 则无论是否出错都会运行，常用于释放资源。最佳实践是尽量捕获具体的异常（如 ValueError），而不是裸写 except:，否则会吞掉意料之外的错误，增加调试难度。
#with 语句
with 语句是 Python 的上下文管理器语法，最典型的用途是自动管理文件等资源。写 with open("data.txt") as f: 后，无论代码块正常结束还是抛出异常，文件都会被自动关闭，无需手动调用 f.close()。自定义上下文管理器只需实现 __enter__ 和 __exit__ 两个魔术方法，或者使用 contextlib.contextmanager 装饰器配合 yield 来简化实现。
#生成器
生成器是一种惰性求值的迭代器，用 yield 关键字代替 return 来逐个产出值。调用生成器函数并不会立即执行全部逻辑，而是每次调用 next() 时才运行到下一个 yield 处暂停，因此即使处理海量数据也只占用极少的内存。生成器表达式与列表推导式写法类似，只是把方括号换成圆括号，例如 (x*x for x in range(1000000))。需要注意的是，生成器只能被消费一次，遍历完后就耗尽了。
#lambda 表达式
lambda 是 Python 中创建匿名小函数的方式，语法为 lambda 参数: 表达式，函数体只能是一个表达式，不能包含多条语句。它特别适合用作 sorted、map、filter 等高阶函数的短小回调，比如 sorted(students, key=lambda s: s.age)。但如果逻辑较复杂，还是应该用 def 定义具名函数，这样代码更易读、也方便调试和复用。
#深浅拷贝
Python 中 a = b 这种赋值只是把新名字绑定到原对象上，并不会复制任何数据。浅拷贝（如 list.copy() 或 copy.copy）只复制最外层容器，内部元素仍然是共享引用；深拷贝 copy.deepcopy 会递归复制所有嵌套层，得到完全独立的对象。修改浅拷贝内层元素会影响原对象，深拷贝则互不影响。需要完全独立的副本时应优先使用 deepcopy，但深拷贝开销较大，处理超大对象时要注意性能。
